About Me

I’m a software developer and ML researcher building end-to-end systems — from real-time anomaly detection pipelines and physics-informed ML models to embedded Linux platforms and full-stack web services. Currently at the Center for Midstream Management and Science (CMMS), I develop production-grade ML systems that operate at sub-millisecond speeds on industrial data streams, combining rigorous physics intuition with modern deep learning. My background spans nuclear physics research at Jefferson Lab (GlueX), backend engineering at a software startup in Kathmandu, and embedded systems for IoT sensor platforms. I care deeply about reproducibility, clean interfaces, and turning research-grade ideas into reliable deployable systems.

Core Expertise

🔬 Physics-Informed ML & Anomaly Detection

Designed real-time anomaly detection systems combining Vector Autoregression (VAR) with tensor train fingerprinting — validated on physical fluid flow testbeds achieving 0.5 ms detection and 1–10 ms forecasting. Built stochastic MPC architectures using Functional PCA and Normalizing Flows for multi-variable distribution prediction.

🧠 Deep Learning & ML Pipelines

Built PyTorch-based ML pipelines with Optuna for hyperparameter optimization on GlueX detector data at Jefferson Lab — improving particle-ID accuracy by 25% and reducing training cycles by 40%. Modular DNN frameworks with gradient monitoring, schedulers, and diagnostics.

🐳 MLOps, Streaming & DevOps

Containerized full anomaly-detection pipelines (Kafka, C++ forecaster, Python analytics) using Docker Compose — cutting onboarding time by 50%. Deployed Prometheus + InfluxDB monitoring with Grafana dashboards, reducing anomaly triage from hours to minutes.

📡 Embedded Systems & Edge Computing

Built embedded Linux solutions on the Octavo OSD32MP1-BRK platform with I2C sensors, Cat-M1/NB-IoT modules, and STM32 ARM Cortex-M4 firmware. Programmed TGS 8410 methane sensors with precise heating cycles and calibrated ADC sampling using STM32CubeIDE.

⚡ Backend Engineering & APIs

Delivered production backend systems at Codavatar — secure authorization with OSO + Python, Twilio-powered APIs, GraphQL + FastAPI + Pandas developer analytics, and Django REST Framework APIs for enterprise clients. Full-stack experience across PostgreSQL, Docker, and async services.

⚛️ C++ & HPC Integration

Deployed particle identification models in C++ within HallD nuclear physics software at Jefferson Lab, enabling real-time data analysis. Custom statistical and physics-inspired models for edge-optimized computation.
